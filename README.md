# 📊 Retail Sales Dashboard

An interactive retail sales analytics dashboard built with Python to visualize sales performance, customer trends, seasonal demand, and business KPIs. The dashboard helps businesses gain actionable insights through dynamic visualizations.

---

## 🚀 Features

- Interactive Sales Dashboard
- Seasonal Sales Analysis
- Revenue & Profit Analysis
- Product-wise Performance
- Customer Trend Analysis
- Monthly & Yearly Sales Reports
- Dynamic Charts & Visualizations
- Excel Data Processing

---

## 🛠 Tech Stack

- Python
- Pandas
- Plotly
- OpenPyXL
- Excel

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Retail-Dashboard.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the dashboard

```bash
python interactive_dashboard.py
```
